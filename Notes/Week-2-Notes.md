This week, I added a new function to my previous micro:bit game. Button A pauses the game, and button B continues the game. And also the opening music. I wanted to make the game easier to control and add another step to the interaction.

I also made a new game called Catching Fruits; basically, it is catching the dropping dots, and there are different music plays when the player gets different scores.

I also tried to make one program with two different games, where button A would start one game and button B would start another. This idea did not work successfully, but I submitted the project because it was part of my experiment and helped me understand the coding process better.

From this experiment, I learned that managing different game states in one program is more complicated than I expected.
